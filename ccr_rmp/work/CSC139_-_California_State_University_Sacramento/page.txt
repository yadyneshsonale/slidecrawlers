Course Description
This course deals with concepts, design principles, fundamental issues and implementations (algorithms and data structures) of modern operating systems. Topics include: operating system structures, processes and threads, concurrency, process communication and synchronization, deadlock and its solutions, processor scheduling, virtual memory management, file systems, I/O device management, security and protection, algorithms and methods from commercial operating systems. Prerequisite: CSC 60 and CSC 137.  3 units.
