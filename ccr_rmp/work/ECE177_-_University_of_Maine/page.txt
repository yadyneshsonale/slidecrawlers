Introduction to computer programming with emphasis on algorithms and an
understanding of underlying hardware. Topics include syntax, variables,
control structures, pointers, operators, functions, and input and
output.

Optional Useful Textbooks
Note: in my experience there aren't really any standout C textbooks.
That, combined with how expensive textbooks tend to be, is why
I don't have a required textbook.  However, with the new "flat-rate"
textbook thing the bookstore does it might be worth reinvestigating
that.  If you feel strongly about this let me know.  Below
are a few texbooks that might be useful if you would like to have one.
"The C Programming Language" by Kernighan and Ritchie.  --
this is the classic book about C, but it is a bit bare bones and
maybe not the best if trying to learn from scratch.
"C Programming for Scientists and Engineers" by Reddy and Ziegler. --
This is what ECE177 used years ago with previous professors.
