Course Objectives
¶
This course is to cover the fundamentals of numerical methods and how that applies to solving engineering problems. At the core of this is using computers to come up with these numerical solutions. There are several tools we can use including:
Python programming language
High-Performance Computing
Using programming and numerical methods to solve engineering problems
Properly document both code and other engineering systems
Learning outcomes
¶
In this course, you will gain hands-on experience with scientific computing techniques, tools, and processes for aerospace design. Through projects, classroom discussions, and laboratory sessions, you will have the opportunity to learn to:
Understand the basic operations of a modern computer and it's limitations
Understand the basics of operating systems including Linux/Unix systems used in High-Performance Computing
Understand and use code management using git and GitHub
Learning outcomes
¶
Be able to write good documentation and understand how to use LaTeX
Practice scientific computing using programming languages, with a focus on understanding how to write generic and robust code to reliably calculate properties of life-sized systems.
Debug code effectively, with a variety of best-practices
Explain and solve real-world aerospace problems utilizing the above tools and techniques.

PreReqs

Prerequisites:  AER E 310, MATH 267, E M 324, E M 345.  Course restricted to AER E juniors and seniors.
It is the policy of the Department of Aerospace Engineering and the College of Engineering to require all students enrolled in this course to have satisfied all of the course's prerequisite requirements. If it is discovered that a student has not met any applicable prerequisite requirements, he/she will be required to immediately drop the course. The failure to drop the course will result in a final course grade of 'F', regardless of course performance. Students who discover they have improperly enrolled in a course without meeting the applicable prerequisite requirements are strongly encouraged to meet with advising staff to promptly drop the course and make alternative scheduling arrangements or discuss if an official waiver of the pre-requisite requirements may be applicable.
