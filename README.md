# slidecrawlers

Code and collected metadata for discovering university course slide pages,
downloading lecture decks, scraping College Class Reviews (CCR), and collecting
course-level Rate My Professors (RMP) data.

## SlideFetch

```bash
cd slidefetch
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m playwright install chromium

# Crawl a known course page.
.venv/bin/python -m slidefetch.cli "https://example.edu/course/slides"

# Search for course pages, then download accepted slide decks.
TAVILY_API_KEY=... .venv/bin/python -m slidefetch.cli \
  --search "operating systems lecture slides"

# Preview without downloading.
.venv/bin/python -m slidefetch.cli "https://example.edu/course/slides" --dry-run
```

Downloaded files are written under `slidefetch/downloads/new/`. Search can use
`TAVILY_API_KEY`, `SERPAPI_API_KEY`, or `SERPAPI_KEY` from the environment; no
keys are stored in this repository.

Useful related entry points:

```bash
cd slidefetch
.venv/bin/python rmp_crawler.py --workers 4 --delay 0.35
.venv/bin/python rmp_course_ratings.py --workers 4 --delay 0.25
.venv/bin/python uw_catalog_crawler.py
.venv/bin/python ccr_label_auto.py --disciplines cs,ece
.venv/bin/python ccr_verify_labels.py
```

## CCR to RMP pipeline

```bash
cd ccr_rmp
python3 -m venv --system-site-packages .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python stage0_excel_to_db.py --example 5
.venv/bin/python run.py --limit 10
```

The pipeline imports CCR courses, fetches each course slide page, extracts an
instructor, resolves the instructor against RMP, and stores only ratings for
the matched course. Stages are resumable. Instructor extraction requires the
configured OpenAI-compatible vision endpoint; see `ccr_rmp/config.yaml` and
`ccr_rmp/knowledge_base.md`.

## Correlation outputs

```bash
cd ccr_rmp_corr
python3 -m venv .venv
.venv/bin/pip install pandas scipy matplotlib openpyxl
./run.sh
```

The analysis writes `merged.csv`, `correlation_report.md`, pairwise correlation
CSVs, matrices, plots, and XLSX exports. The primary recorded result is a
moderate positive relationship between CCR course stars and RMP course quality
($r=0.496$, $n=73$).

## Earlier crawlers

`scraper/` (SlideGrab), `slidehunt/`, and `slideratings/` preserve predecessor
implementations and their databases, spreadsheets, audits, web caches, and run
logs. They are retained because each contains unique crawl logic or results not
present in the current `slidefetch/` implementation. See each package's CLI,
`run.sh`, or README for its entry point.

`archive/ccr-rmp-code/` contains only the six historical SQLite files whose
content differs from the current canonical databases. Identical copied source
files and the unrelated downstream `mcq_bench` were not duplicated.

## Data notes

- The datasets are snapshots of public web pages and APIs, not live mirrors.
- RMP search results are school-checked to reduce same-name collisions.
- RMP `class` values are user-entered strings; normalization is pipeline-specific.
- Logs include failed requests and resumable progress, so they are retained as
  provenance rather than treated as clean tabular outputs.
- Review third-party site terms and applicable privacy requirements before
  redistributing or refreshing scraped data.
